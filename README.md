# RUSTWATCH

Статический каталог Rust-серверов для GitHub Pages. Игроки могут искать серверы, фильтровать и сортировать список, копировать команду подключения, сохранять избранное и собирать локальные карточки в профиле.

## Безопасное обновление каталога

Список серверов загружает GitHub Actions из API BattleMetrics.ru и публикует как статический JSON-файл. API-ключ используется только в workflow и не попадает в браузерный JavaScript или файлы сайта.

Перед первым запуском:

1. Открой **Settings → Secrets and variables → Actions**.
2. Создай repository secret с именем `BATTLEMETRICS_API_KEY` и вставь ключ BattleMetrics.ru.
3. Открой **Settings → Pages** и выбери **GitHub Actions** как источник публикации.
4. Запусти workflow **Update server catalogue and publish** через **Actions → Run workflow** или дождись первого запуска по расписанию.

Workflow публикует страницу при изменениях в `main` и обновляет каталог по расписанию примерно раз в пять минут. GitHub может запускать запланированные workflow с задержкой.

Профиль открыт через `profile.html`. Баланс, награды по 2 монеты раз в 30 минут и карточки хранятся в `localStorage` браузера: они не синхронизируются между устройствами и могут быть сброшены очисткой данных браузера.

Источник каталога: [BattleMetrics.ru](https://battlemetrics.ru/).
